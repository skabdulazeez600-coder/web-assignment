# HTML, CSS & JavaScript Practical Programs

A complete practical-program website containing the HTML, CSS, and JavaScript experiments from the supplied practical list, through the Mini Projects section.

## Sections

- HTML — 15 programs
- CSS — 75 programs
- JavaScript — 67 programs
- DOM Manipulation — 15 programs (the first DOM section only)
- Events — 8 programs
- Forms & Validation — 7 programs
- Browser & Storage — 8 programs
- Mini Projects — 17 projects

## Mini Projects

The JavaScript section includes 17 mini projects, including a digital calculator, digital clock, stopwatch, countdown timer, to-do list, weather application, quiz, number guessing game, tic-tac-toe, expense tracker, student marks/grade calculator, shopping cart, notes app, random password generator, BMI calculator, currency converter, and interactive portfolio.

## Running the Website

Open `index.html` in a web browser. Each section has its own program list and individual HTML program pages.
